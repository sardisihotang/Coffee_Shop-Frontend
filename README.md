## 📌 Tentang Proyek / About the Project

**[ID]** Proyek ini adalah antarmuka pengguna (User Interface) berbasis web statis untuk kedai kopi. Dirancang sebagai landing page yang elegan, aplikasi web ini menampilkan navigasi modern, logo kustom, dan elemen visual yang menarik untuk memperkenalkan produk serta informasi kedai kepada pengunjung.

**[EN]** *This project is a static web-based User Interface for a coffee shop. Designed as an elegant landing page, this web application features modern navigation, a custom logo, and engaging visual elements to introduce products and shop information to visitors.*

---

## 🚀 Fitur Utama / Key Features

**[ID]**
* **Navigasi Responsif:** Dilengkapi dengan menu bar dan header interaktif untuk memudahkan mobilitas pengunjung di dalam halaman web.
* **Ikonografi Modern:** Mengintegrasikan library *Boxicons* untuk menampilkan ikon yang tajam, ringan, dan profesional.
* **Desain Estetik:** Tata letak dan gaya kustom yang berfokus pada kenyamanan visual khas kafe/kedai kopi.

**[EN]**
* **Responsive Navigation:** Equipped with an interactive menu bar and header to ensure smooth visitor mobility throughout the webpage.
* **Modern Iconography:** Integrates the *Boxicons* library to deliver crisp, lightweight, and professional icons.
* **Aesthetic Design:** Custom layouts and styles focused on the visual comfort typical of a coffee shop.

---

## 🛠️ Teknologi & Library / Technology & Libraries

* **Struktur (Structure):** HTML5
* **Gaya (Styling):** CSS3 (Custom Stylesheet)
* **Interaktivitas (Interactivity):** JavaScript
* **Ikonografi (Iconography):** Boxicons
